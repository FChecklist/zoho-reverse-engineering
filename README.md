# Zoho Reverse Engineering

Reverse-engineering documentation of Zoho CRM and Zoho Projects, built by navigating
a live logged-in session (Owner-authenticated, browsed via Claude in Chrome) and
recording screen structure, fields, and workflows.

Scope: this repo holds scraped documentation of a THIRD-PARTY system (Zoho), not
VERIDIAN's own application code -- same classification as odoo-reverse-engineering
and infisuite-reverse-engineering (see MASTER_INDEX.yaml system_boundary.repos.reverse_engineering).

## Structure
- docs/crm/ -- Zoho CRM module documentation (fields, screens, workflows)
- docs/projects/ -- Zoho Projects module documentation
- screenshots/crm/ -- Zoho CRM screenshots
- screenshots/projects/ -- Zoho Projects screenshots
